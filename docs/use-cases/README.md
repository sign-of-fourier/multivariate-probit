# Use cases

Problems that fit the multivariate probit's shape: several correlated 0/1
outcomes labelled on the same rows, and a decision that turns on a
combination of them. Each page states the problem, the joint query that
answers it, and a runnable example on synthetic data. These are shapes the
model fits, not reports of deployments.

- [Fusing fraud and identity vendor scores](fraud-vendor-fusion.md)
- [Claims fast-track eligibility](claims-fast-track.md)
- [HCC codes with hierarchies and interactions](hcc-codes.md)
- [Content moderation and ad integrity](content-moderation.md)
- [Cyber: phishing and exploited vulnerabilities](cyber.md)
- [Property imagery attributes](property-imagery.md)

Have a problem of this shape? Open a
[use-case issue](https://github.com/sign-of-fourier/multivariate-probit/issues/new?template=use-case.md).
